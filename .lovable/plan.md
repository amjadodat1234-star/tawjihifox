# خطة "توجيهي فوكس V2" — منصة فيها قيمة حقيقية

الفكرة: بدل ما نكون موقع روابط زي "مدارك جو"، نصير **رفيق ذكي للطالب** — الطالب يدخل، المنصة تعرف نقاط ضعفه، تشرح له، تختبره، وتذاكر معه. هذا اللي يخلي الناس ترجع كل يوم.

## المحاور الأربعة اللي تعطي قيمة

### 1. مساعد AI "أستاذ فوكس" (الميزة النجمة)
- شات بيشتغل بـ Lovable AI (Gemini) متخصص بمنهاج التوجيهي الأردني.
- 3 أوضاع بضغطة زر:
  - **اشرحلي**: يشرح مفهوم/آية/قاعدة بلغة سهلة + مثال.
  - **اختبرني**: يولّد 5 أسئلة على أي موضوع + يصحح + يفسّر الغلط.
  - **لخّصلي**: الطالب يلصق نص/فقرة ويرجعله ملخص منظم بنقاط.
- محادثات محفوظة (Threads) لكل مادة.
- كل جواب فيه زر "أضِفه لبنك مراجعتي" (يصير بطاقة flashcard تلقائياً).

### 2. بنك أسئلة ذكي + تحليل الضعف
- كل سؤال مربوط بمادة/وحدة/مهارة.
- بعد كل جلسة اختبار: رسم بياني (Radar chart) يبيّن نسبة إتقانك لكل وحدة.
- المنصة تقترح تلقائياً: "ضعفك في `الاشتقاق البلاغي`، جرّب هالـ 10 أسئلة".
- قائمة "أخطائي" — كل سؤال غلطت فيه يظهر بصفحة خاصة مع الشرح.

### 3. خطة مذاكرة تكيّفية
- الطالب يدخل تاريخ التوجيهي.
- المنصة تحسب الأيام المتبقية × الوحدات × نقاط ضعفك = **جدول يومي** يتكيّف تلقائياً.
- كل يوم يفتح المنصة يلاقي: "اليوم عندك: مراجعة قواعد + 20 سؤال تاريخ + جلسة تركيز 45د".
- إشعارات وشريط تقدم أسبوعي.

### 4. غرف مذاكرة جماعية Live
- طالب يفتح غرفة → رابط قابل للمشاركة.
- تايمر مشترك (كل الأعضاء يشوفوا نفس العد التنازلي).
- Presence مباشرة (مين موجود، مين مذاكر، مين بستراحة).
- شات جانبي داخل الغرفة.
- Leaderboard الغرفة (مين ذاكر أكثر اليوم).

## الهوية البصرية — Neo Study
- الخلفية: `#ffffff` مع لمسات `#f8fafc`.
- النص الأساسي: `#0f172a`.
- Primary (بنفسجي حيوي): `#8b5cf6`.
- Success/Accent (أخضر): `#22c55e`.
- الخطوط: **Sora** للعناوين (حديث وجريء) + **Manrope** للنص.
- انيميشن: framer-motion بحركات ناعمة (spring)، بدون aurora dark heavy.
- كل بطاقة فيها micro-interaction (glow خفيف عند الـ hover).

## قاعدة البيانات (جداول جديدة)

- `ai_chats` + `ai_messages` (مع thread_id لكل محادثة).
- `question_bank` (subject, unit, skill, difficulty, question, choices, answer, explanation).
- `question_attempts` (user_id, question_id, correct, answered_at).
- `flashcards` (user_id, front, back, next_review, ease_factor) — SRS مبسط.
- `study_plans` (user_id, target_date, subjects, generated_plan JSONB).
- `study_rooms` + `room_members` + `room_messages`.

## خارطة التنفيذ — 3 مراحل

**المرحلة 1 (هالجلسة):**
- Migration للجداول الجديدة.
- إعادة تصميم الـ theme إلى Neo Study + خطوط Sora/Manrope.
- بناء صفحة `/tutor` — مساعد AI "أستاذ فوكس" مع 3 أوضاع.
- بناء صفحة `/plan` — خطة المذاكرة التكيفية.
- تحديث الصفحة الرئيسية لتعرض القيمة الجديدة بوضوح.

**المرحلة 2 (الجلسة الجاية):**
- بنك الأسئلة الذكي + تحليل الضعف (Radar chart + قائمة الأخطاء).
- Flashcards + SRS.

**المرحلة 3:**
- غرف المذاكرة الجماعية Live مع Supabase Realtime + Presence.

## أسئلة تقنية للمستخدم قبل ما أبدأ

1. **محتوى بنك الأسئلة**: عندك بنك أسئلة جاهز (Excel/PDF) تبعتلي إياه، أو تبيني أولد أسئلة تجريبية بـ AI للبداية وبعدين تضيف الحقيقية عن طريق لوحة الأدمن؟
2. **موافق نبدأ بالمرحلة 1 هذي الجلسة**؟ (المساعد الذكي + الخطة التكيفية + الثيم الجديد = أكثر شي بيغيّر إحساس الموقع فوراً)
